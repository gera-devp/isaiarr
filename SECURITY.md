# Security

Isaiarr is meant to run on your home network. If you reach it from outside, use a VPN such as
Tailscale and turn on the login (Settings → Login); don't expose the port to the internet.

Found a security problem? Please don't open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/gera-devp/isaiarr/security/advisories/new).
